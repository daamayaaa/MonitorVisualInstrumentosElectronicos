Intalación

1. En el equipo donde se utilizará esta aplicación debe estar instalada la máquina virtual de Java JDK 1.7.0_79 o superior.

2. En la configuración avanzada del sistema, variables de entorno deben estar configuradas las siguientes variables:

- JAVA_HOME (Configuración obligatoria para que el programa funcione correctamente).

- ANT_HOME (Configuración requerida para que el desarrollador pueda hacer actualizaciones sobre el software).

3. Descomprimir la carpeta librerias que vienen anexas al proyecto y alojarlas en el siguiente orden.

- En la ruta C:\Program Files (x86)\Java\jdk1.7.0_79\jre\lib\ext debe alojar el JAR RXTXcomm.jar.

- En la ruta C:\Program Files (x86)\Java\jdk1.7.0_79\jre\bin debe alojar el ejecutable rxtxSerial.dll.

4. Asegurese de que se encuentren en el documento del instalador las siguientes carpetas.

- conf (Archivo de configuración que contiene los logs de ejecución del proyecto).

- imagenes (Imágenes requeridas para que funcione la interfaz).

5. En el equipo donde va a probar la aplicación asegúrese de que las siguientes carpetas estén creadas:

- C:\co\edu\unal\fing\diee\ingelect\proyinv\cliente\logs

- C:\co\edu\unal\fing\diee\ingelect\proyinv\comserial\logs

- C:\co\edu\unal\fing\diee\ingelect\proyinv\graficas\logs

Estas carpetas son obligatorias porque en estas rutas se generarán los logs de la aplicación.

6. Ejecutar el programa EjecutarMonitorVisualGota.bat.

7. Para actualizar la información del manual de usuario:

1. Descargar la utilidad JavaHelp (alojarla preferiblemente en C:\).

2. Luego se ubica desde una consola a la ruta: C:\Eclipse Luna\workspace\MonitorVisualGota\help

3. Inmediatamente después presionar el siguiente comando: java -jar C:\Javahelp\javahelp\bin\jhindexer.jar html

3. Automáticamente el generará en \help una carpeta llamada JavaHelpSearch.
